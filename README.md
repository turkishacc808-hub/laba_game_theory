# Лабораторная работа: Решение матричных игр

Данный проект представляет собой веб-приложение для анализа и решения матричных игр в рамках курса «Теория игр». Приложение разработано с использованием React, TypeScript и Vite, и позволяет проводить полный цикл анализа платежной матрицы.

## Реализованные методы и алгоритмы

1. **Поиск седловой точки** 
   - Нахождение нижней и верхней цены игры (максимин и минимакс).
   - Определение наличия седловой точки и решения в чистых стратегиях.
2. **Метод доминирования**
   - Автоматическое исключение доминируемых строк (для Игрока А) и столбцов (для Игрока B).
   - Пошаговое сокращение размерности платежной матрицы.
3. **Аналитическое решение для матриц 2x2**
   - Расчет оптимальных вероятностей выбора стратегий $p$ и $q$, а также цены игры $v$.
4. **Метод Брауна-Робинсон (итеративный метод)**
   - Нахождение приближенного решения путем фиктивного разыгрывания партий.
   - Визуализация сходимости верхней и нижней оценок цены игры на графике.
5. **Симплекс-метод**
   - Сведение задачи теории игр к задаче линейного программирования.
   - Точное вычисление цены игры и оптимальных смешанных стратегий для матриц произвольной размерности.

## Функционал приложения

- **Интерактивный ввод матрицы**: удобный интерфейс для задания размерности и заполнения элементов платежной матрицы.
- **Пошаговое решение**: возможность просмотра результатов каждого этапа анализа (от проверки седловой точки до симплекс-метода).
- **Визуализация графиков**: построение графика сходимости метода Брауна-Робинсон с использованием Chart.js.
- **Генерация отчета (PDF)**: автоматическое формирование детализированного отчета с результатами вычислений, таблицами и графиками.

## Стек технологий

- **Frontend**: React 19, TypeScript
- **Сборка**: Vite
- **Графики**: Chart.js / react-chartjs-2
- **Экспорт в PDF**: jsPDF, jspdf-autotable
- **Иконки**: Lucide React
- **Анимации**: Framer Motion

## Запуск проекта локально

Для запуска проекта на вашем компьютере выполните следующие шаги:

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (рекомендуется версия 18 или выше).
2. Склонируйте репозиторий или распакуйте архив с проектом.
3. Перейдите в директорию проекта:
   ```bash
   cd laba_game_theory
   ```
4. Установите зависимости:
   ```bash
   npm install
   ```
5. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
6. Откройте предоставленную в терминале ссылку (обычно `http://localhost:5173`) в браузере.

## Структура проекта

- `src/math/gameTheory.ts` — ядро вычислительной логики (реализация всех алгоритмов теории игр).
- `src/reportEngine.ts` — генератор PDF-отчетов.
- `src/App.tsx` — главный компонент приложения, связывающий интерфейс с вычислениями.
- `src/index.css` — основные стили приложения (включая адаптивную верстку и цветовую палитру).

## Сборка для продакшена

Для создания оптимизированной сборки проекта выполните команду:
```bash
npm run build
```
